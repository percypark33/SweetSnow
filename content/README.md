# Content

Working folders for the `content-creator` agent.

| Folder | What goes in it | In git? |
|---|---|---|
| `references/` | Viral videos to copy the format of (analysis only) | No |
| `footage/` | Sweet Snow's raw clips: shaves, topping drops, spoon pulls, reactions | No |
| `formats/` | Format breakdowns (shot timing, text overlays, hook), one `.md` per format | Yes |
| `out/` | Finished videos, cover frames, caption drafts | No |

Video files stay out of git because they're too big. On the go, drop clips in the
Google Drive folder "Sweet Snow Content/Footage" instead; the agent can pull small
ones from there.
